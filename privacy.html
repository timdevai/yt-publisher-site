yt-publisher privacy policy

Last updated 2026-10-06.

yt-publisher is a personal command-line tool run by a single operator to upload videos to YouTube channels that the operator owns and to read the analytics of those channels. It is not offered to the public and has no users other than its operator.

Google user data

The tool requests Google OAuth access with the scopes youtube.upload, youtube.force-ssl and yt-analytics.readonly, only for channels the operator owns. That access is used solely to upload videos, set thumbnails, read video metadata, and read channel analytics and reporting data for those channels.

Access and refresh tokens are stored locally on the operator's own computer and are never sent to any server or third party. The tool stores no data on any server, collects no information about viewers or any other person, does not sell or share data, and does not use Google user data for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token store removes all stored credentials.
